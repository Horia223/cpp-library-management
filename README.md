# Library Management System

This project was developed as part of my studies at Babeș-Bolyai University, Faculty of Mathematics and Computer Science, for the Object-Oriented Programming course.

I built it to practice C++, understand object-oriented programming, explore Qt for graphical user interfaces, and learn how to organize and document a software project using Git and GitHub.

## Features

- Manage books and library records
- Perform library operations through a graphical interface
- Organize and display information about books

## Concepts & Technologies

- **C++ and OOP** — classes, objects, encapsulation, and separation of responsibilities
- **Object-Oriented Design** — organizing application logic into classes and modules
- **Qt** — building a graphical user interface
- **Event-Driven Programming** — handling user interactions through Qt signals and slots
- **Exception Handling** — handling errors and invalid operations
- **Visual Studio** — developing and building the application
- **Git & GitHub** — practicing version control and project documentation

## How to Run

Open the project in Visual Studio, configure the required Qt installation and build settings, then build and run the application.

This is an educational project focused on learning and practicing object-oriented programming in C++.
